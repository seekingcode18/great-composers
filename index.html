Opening this on your phone

Save the file as composer-stories.html. On Android, find it in Downloads or your Files app and choose a web browser to open it. Some file-preview apps only show the code; use a browser if that happens.

The stories, facts, portraits and navigation are all inside this one file, so they work without an internet connection. YouTube recordings and source pages need internet access. YouTube links open separately so you can return to your place here; some start part-way through a longer album.

Reading, teaching and saved progress

Use A− and A+ in the top bar to change the reading size. Each story has four paragraphs and is roughly two minutes at a relaxed adult reading pace; leave extra time for questions and music.

Tap Mark as taught after a lesson; tap again to undo it. Progress and reading size are saved in this browser when storage is available. They do not sync between devices. Private browsing, clearing browser data, or moving or renaming the HTML file can reset them. If saving is blocked, the controls still work for the current visit and a message will tell you.

No sign-in or installation is needed. The page makes no background requests. Listening choices include direct recordings and clearly labelled YouTube searches for suggested performers. A search opens results for you to choose from; it is not a preselected recording. A 30–60 second extract is often enough for a first listen.

A few musical words

Composer: someone who creates music. Orchestra: a large group of musicians. Concerto: a piece where a solo player, or small group, shares music with an ensemble. Sonata: a piece for instruments, usually in several sections. Symphony: a large piece for orchestra. Choir: a group of singers.

Baroque, Classical and Romantic are names for overlapping chapters in music history. They help us talk about styles; people did not all change how they wrote on the same day. Op. and BWV are labels that help identify particular pieces.

Adding more composers later

The content is kept in a single, clearly labelled COMPOSER DATA section inside this HTML file. Open the file in a text editor, find id="composers-data", copy one composer’s JSON object and replace its information. Give it a unique id, such as handel. Keep the JSON valid, including commas between objects.

Each object has a name, surname, dates, era, country, quick facts, story paragraphs, listening pieces, a discussion prompt and sources. On opening in a browser with JavaScript enabled, the alphabet and surname lists rebuild automatically. Existing progress uses the stable composer IDs, so keep those IDs when updating a story.

An optional portrait object holds an embedded image, its caption and source credit. Keep the image credit and licence with the picture. Later imagined portraits and uncertain likenesses are labelled; some early composers have no confirmed portrait to include.

JavaScript builds the collection directly from the data in this file. No separate installation or build step is needed after an edit. A future hosted version could add installability or shared progress; the downloaded version already keeps all its reading content offline.
